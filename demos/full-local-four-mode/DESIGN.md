# Full Local Four-Mode Demo Composition

This HyperFrames composition is an offline, project-authored validation source.
It uses no remote asset, font, model, or downloaded media.

## Visual identity

- Obsidian: `#0B0E10`
- Deep Graphite: `#151A1D`
- Soft Ivory: `#F1F4EF`
- Scope Cyan: `#56E0D0`
- Signal Violet: `#8D7DF7`
- Diagnostic Lime: `#B7F36A`
- Warning Amber: `#F6B84A`
- Critical Coral: `#FF6F61`

Typography uses local system sans-serif fonts with tabular numerals. Motion is
functional only: scan lines, timecode movement, range highlighting, and
evidence markers. It avoids remote assets, decorative particles, excessive
glow, and science-fiction HUD clutter.

## Reduced motion

When reduced motion is requested, scan movement and range transitions become
static while all labels, timecodes, selected ranges, and evidence markers
remain visible.

## Privacy panel

From 25 to 32 seconds, the fixed right-side privacy panel remains wholly within
the normalized bounding box `[0.58, 0.18, 0.94, 0.78]`. It only displays the
three fictional identifiers declared in `demo-contract.json`.
